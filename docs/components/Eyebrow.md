# Eyebrow

A short uppercase, tracked label that sits directly above a headline, in `svr-color-accent`.

**Provide:** `children` (2–4 words), optional `as` element.

- Always followed by a Bebas Neue heading (`svr-display-h1` or `svr-subheading-h2`).
- Red in light mode, the #E07B72 tint in dark mode, and off-white inside a red band. All of this is automatic.
- Never use it as a standalone heading or for sentences.
