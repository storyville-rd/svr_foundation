# SectionHeader

A numbered section title over a 3px red accent rule, as used in Storyville documents ("01 — Color Palette").

**Provide:** `children` (the title), optional `number` ("01", "02"…), optional `level` (heading level, default 2).

- Use for the top-level sections of proposals, reports and long pages; number sections in order with two digits.
- Title is `svr-subheading-h2` in `svr-color-heading`; the number and rule are `svr-color-accent`.
