# Logos

Storyville RD's mark (a rectangle cut by a winding S-shaped road), wordmark ("STORYVILLE" light, "RD" bold) and tagline ("YOUR PATH. YOUR STORY"). All are transparent PNGs in two single-ink versions:

- **charcoal** (ink #211D1B, `svr-palette-charcoal`): use on light grounds, meaning light mode pages and `svr-color-surface-alt`.
- **offwhite** (ink #FAF8F5, `svr-palette-offwhite`): use on dark and red grounds, meaning dark mode pages, inverse bands in light mode and red bands.

Apps that toggle themes swap the file with the theme (or show the right one with `<picture>` or CSS).

| File | Use | Alt text |
| --- | --- | --- |
| `storyville-logo-stacked-*` | Primary logo: mark above wordmark and tagline. Covers, title slides, end cards. | `Storyville RD. Your Path. Your Story.` |
| `storyville-logo-horizontal-*` | Mark beside the wordmark, no tagline. Headers, letterhead, email signatures. | `Storyville RD` |
| `storyville-wordmark-*` | Wordmark alone, where space is tight or the mark appears nearby. | `Storyville RD` |
| `storyville-mark-*` | The S-road mark alone. Favicons, avatars, watermarks. | `Storyville RD` when it stands alone; `alt=""` when the name is written beside it |

- Alt text is the text the logo contains, written out in full; never add "logo" or "image of".
- Never redraw, recolor, stretch or rebuild the logo in live type; always place one of these files.
- Never place the charcoal version on dark or red grounds, or the off-white version on light grounds.
